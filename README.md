## Description
This repository contains the code and data used for **Rethinker: A three-stage efficient inference framework for large language models**. The workflow includes:
1. SFT data generation from DeepScaleR samples.
2. SFT training.
3. M-TGRPO training.
4. Evaluation on GSM8K, MATH-500, and AIME-2025.

## Repository Structure
```text
./
├── data/
│   ├── deepscaler_select_25k.parquet   # Selected DeepScaleR samples for M-TGRPO training
│   └── SFT_7k.jsonl                    # SFT training data
├── scripts/                             # Helper scripts for verl and model merging
├── verl/                                # verl-related scripts

├── tests/                               # Evaluation scripts
└── requirements.txt                    # Additional packages for GRPO training
```

## Dataset Information
### Local data files
- `data/deepscaler_select_25k.parquet`: selected from the original DeepScaleR dataset. Samples with incorrect answers, unparseable answers, or other low-quality responses were excluded. This file is used both for SFT data generation and M-TGRPO training.
- `data/SFT_7k.jsonl`: SFT training data. It can be generated by running `src/data_process/run.sh`, which calls `gen_sft_data.py`.

### Third-party datasets
The following external datasets are used.

- DeepScaleR: [🤗 HF Repo](https://huggingface.co/datasets/agentica-org/DeepScaleR-Preview-Dataset)
- GSM8K: [🤗 HF Repo](https://huggingface.co/datasets/openai/gsm8k)
- MATH-500: [🤗 HF Repo](https://huggingface.co/datasets/HuggingFaceH4/MATH-500)
- AIME-2025: [🤗 HF Repo](https://huggingface.co/datasets/math-ai/aime25)

The test datasets GSM8K, MATH-500, and AIME-2025 are used as provided. No additional preprocessing is applied. Evaluation is performed with EvalScope.

## Code Information
- `src/data_process/`: scripts for generating SFT data.
- `src/swift_sft/`: SFT training scripts.
- `src/dapo/`: M-TGRPO training scripts.
- `tests/`: evaluation scripts.

## Requirements
### SFT / ms-swift environment
Use the following ms-swift image:
```text
modelscope-registry.cn-hangzhou.cr.aliyuncs.com/modelscope-repo/modelscope:ubuntu22.04-cuda12.4.0-py310-torch2.6.0-vllm0.8.5.post1-modelscope1.28.1-swift3.6.4
```

Inside the container, additionally install:
```bash
pip install "math-verify>=0.8.0"
```

### GRPO / verl environment
- Follow the verl documentation: https://verl.readthedocs.io/en/v0.4.1/
- Recommended Docker image:
  `whatcanyousee/verl:ngc-cu124-vllm0.8.5-sglang0.4.6.post5-mcore0.12.1-te2.3-deepseekv3`
- Install verl and the additional packages in `requirements.txt`.

### Evaluation environment
- `evalscope==0.17.1`

## Usage Instructions

### 1. Create the SFT / ms-swift environment
Use the ms-swift image listed in the Requirements section. After entering the container, install:
```bash
pip install "math-verify==0.8.0"
```

### 2. Generate SFT data
Input:
- `data/deepscaler_select_25k.parquet`

Run:
```bash
# Confirm paths and parameters in the script before running
bash src/data_process/run.sh
```

### 3. Run SFT training
Input:
- `data/SFT_7k.jsonl`

Run:
```bash
# Confirm parameters in the script before running
bash src/swift_sft/run_sft.sh
```

The output checkpoint location is controlled by the SFT training script.

### 4. Create the GRPO / verl environment
1. Launch the recommended Docker image and attach to it:
```bash
docker create --runtime=nvidia --gpus all --net=host --shm-size="10g" --cap-add=SYS_ADMIN -v .:/workspace/verl --name verl <image:tag>
docker start verl
docker exec -it verl bash
```

2. Inside the container, install verl:
```bash
git clone https://github.com/volcengine/verl && cd verl
# Choose one of the following:
# pip3 install -e .[vllm]
# pip3 install verl[vllm]
```

3. Install additional packages:
```bash
pip install -r requirements.txt
```

### 5. Run M-TGRPO training
Before training, confirm the parameter values in the GRPO script. Then run:
```bash
bash src/dapo/run_grpo_deepseek_qwen_1.5B.sh
```

After training, merge the model:
```bash
# Confirm parameters before running
bash scripts/merge_model.sh
```

The trained model is available on Hugging Face: [🤗 HF Repo](https://huggingface.co/YTChan/Rethinker-1.5B)

### 6. Evaluation
Evaluation is performed with EvalScope on GSM8K, MATH-500, and AIME-2025. The test datasets are used without additional preprocessing.

First deploy the trained model with vLLM:
```bash
# Confirm parameters before running
bash tests/run_vllm.sh
```

Then run the evaluation entry:
```bash
# Confirm parameters before running
python tests/math_eval.py
```
